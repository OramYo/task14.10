# מעבדת GitHub Actions

אתר סטטי ב־HTML ו־CSS עם פריסה אוטומטית ל־GitHub Pages בכל Push לענף main.

אתר: https://oramyo.github.io/task14.10/

Workflow: `.github/workflows/deploy.yml`

שלבי הפריסה: Checkout → Setup Pages → Upload Artifacts → Deploy to GitHub Pages.

מבוסס על [תבנית boxbot6](https://github.com/boxbot6/website-template-simple-single-page-v1), ברישיון MIT המצורף.
